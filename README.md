# 🧠 Simon Game

A classic memory-based color sequence game built using **HTML, CSS, and Vanilla JavaScript**.

The game challenges the player to remember and reproduce an increasingly complex sequence of colors. Each level adds a new step to the sequence, testing the player's memory and concentration.

---

## 🎮 Game Overview

Simon Game is a pattern recognition game where:

- The system generates a random color sequence.
- The player must repeat the exact sequence by clicking the colored buttons.
- With each successful level, a new color is added.
- A wrong click results in a game over.

The game can be restarted by pressing any key.

---

## 🚀 Features

- Dynamic level progression
- Random sequence generation
- Interactive button animations
- Sound effects for each color
- Game over feedback with sound and visual effect
- Keyboard event-based game start
- Clean retro-style UI design
